# Byline

A small local-first writing editor for comparing a rough draft against an edited version.

## Setup

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
npm run test
```

## Notes

* Built with Vite, React, TypeScript, and Tailwind CSS.
* No backend.
* Draft/editor content is stored locally in the browser.
* Editor panes are powered by CodeMirror.
